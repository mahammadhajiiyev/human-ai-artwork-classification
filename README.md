# Human vs AI Artwork Classification

A computer vision project that classifies artwork images by **art style and origin** — whether a piece was made by a human or generated by AI (e.g. `Human_Pop_Art` vs its AI-generated counterpart).

## Dataset

Kaggle **Human & AI Artwork** dataset (`human-ai-artwork`). The notebook splits it into `train` / `val` / `test` folders before training.

## Models

Images are resized to `224x224`. Two approaches are compared:

1. **Custom CNN** built from scratch, with `EarlyStopping`
2. **ResNet50 transfer learning** — ImageNet-pretrained base with a new softmax head, then fine-tuned

The notebook ends with a helper that predicts the class of any new image.

## Results & next steps

This is the most challenging of my image projects: the ResNet50 model fits the training set well (~93% accuracy) but validation accuracy stays around ~52%, which shows overfitting. Possible improvements: stronger data augmentation, more regularization, and merging visually similar classes.

## How to run

The notebook was written for **Kaggle Notebooks**. Add the `human-ai-artwork` dataset to the notebook, enable a GPU, and run the cells in order.

## Technologies

Python, TensorFlow / Keras, ResNet50, NumPy, pandas, Matplotlib
